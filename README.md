# Voice Assistant with ElevenLabs

This project is a simple real-time voice assistant built with Python and the ElevenLabs Conversational AI API. It listens to your voice, understands your question, and replies with a lifelike voice response in real time.

---

## Features

- Record voice input using your microphone
- Understands your message via ElevenLabs Conversational AI
- Speaks back a natural voice response in real time
- Uses `.env` for secure API key and Agent ID management

---

## Tech Stack

- Python 3.11
- `elevenlabs`
- `python-dotenv`
- `PyAudio`
